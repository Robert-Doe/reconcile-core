Seven ThingsEvery Module Assumes

You already know JavaScript. This page is not a JS course — it is the short list of mechanical primitives the reconciliation modules lean on without re-explaining. If a module's diagram or code stops making sense, the fix is almost always "come back here," not "re-read the module."

Why a separate layer instead of teaching inline

Every module tags the specific primitive it needs at the top, as a link back here. That way a module's own space is spent entirely on what's new, never on re-deriving something you already used three modules ago.
