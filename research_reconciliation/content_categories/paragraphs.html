Paragraphs: the concept, not just <p>

Surprise: in the spec, a "paragraph" is not the <p> element. It's an abstract structural unit — a run of phrasing content — that exists whether or not you wrapped it in any tag. The <p> element just makes one explicit.

The definition

A paragraph is "typically a run of phrasing content that forms a block of text with one or more sentences," but the spec generalizes it: an address, part of a form, a byline, or a stanza is also a paragraph. It's a thematic run of phrasing, not a specific element.

How paragraphs are delimited (the algorithm, simplified)

Inside an element that accepts both phrasing and non-phrasing content (like a <div>), the spec finds paragraphs like this:

  1. Walk the child nodes.
  2. Each run of sibling phrasing nodes, uninterrupted by non-phrasing content, is a candidate paragraph.
  3. The run is a paragraph if it contains at least one node that is not just embedded content or inter-element whitespace.
  4. The transparent straddlers a, ins, del, map are ignored when finding boundaries (they can span across).

So two text runs separated by a <div> or an <h2> are two paragraphs; text and an <em> and more text in a row are one.

When do you actually need <p>?

The spec's guidance: use <p> to wrap individual paragraphs "when there would otherwise not be any content other than phrasing content to separate the paragraphs from each other." I.e. if two phrasing runs sit next to each other with nothing block-level between them, they'd merge into one paragraph — so you add <p> to keep them distinct.

<!-- one paragraph (runs merge): -->
<div>First thought. Second thought.</div>

<!-- two paragraphs (explicitly separated): -->
<div><p>First thought.</p><p>Second thought.</p></div>
🧠 Brain Power — the tie to security
Why would a security researcher care about an abstract paragraph model? Because it's another place where structure is computed from a run of nodes, and transparent elements are deliberately skipped. Any algorithm that "ignores a/ins/del/map when scanning" is an algorithm an attacker can hide inside — content that a scanner skips can carry a payload a sink later honors. The paragraph algorithm is a benign example of the same node-run-scanning pattern that, in sanitizers, becomes a bypass.
