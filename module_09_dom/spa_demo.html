Mini SPA (intentionally vulnerable)

This page is a client-side app. The server never sees your payload — everything happens in the browser. It reads the URL fragment (location.hash) and renders it. That is a textbook source → sink DOM XSS.

The vulnerable code (read it)

function render() {
  const raw = decodeURIComponent(location.hash.slice(1)); // SOURCE
  document.getElementById('route').textContent = raw || '(none)';

  if (raw.startsWith('profile/')) {
    const who = raw.slice('profile/'.length);
    // SINK: innerHTML with attacker-influenced string
    document.getElementById('content').innerHTML = 'Profile of ' + who;
    document.getElementById('title').textContent = 'Profile';
  } else if (raw === 'about') {
    document.getElementById('content').textContent = 'About this app.';
  } else {
    // SINK: the whole fragment flows into innerHTML
    document.getElementById('content').innerHTML = raw || 'Home';
  }
}
window.addEventListener('hashchange', render);
render();
