Reconstruct the Samy worm in your own lab

The Samy case study ships a de-fanged mini-worm that propagates through the Module 10 comment board (/comments): each viewer's browser posts the worm again as a new comment, so the payload spreads to everyone who reads the page. It carries no real payload beyond a visible marker and a Module 11 callback — it exists to let you watch exponential propagation safely on localhost.

What every case has in common

  1. The alert was never the point. Each incident's impact came from what same-origin JS did next (self-post, exfiltrate, skim) — exactly Module 15's lesson.
  2. A single mechanism, industrialized. None used exotic zero-days; they used a well-known mechanism at scale against a missing baseline defense (output encoding, CSP, subresource integrity, script isolation).
  3. The defense existed but wasn't deployed. Contextual encoding, CSP, SRI, and payment-field isolation would each have prevented or contained the corresponding case. Your Module 18 gap analysis should be able to name, for every case here, the control that would have stopped it.
